Two hues, four jobs, one law
Amber filled
The one most consequential action on the screen. Maximum one.
Amber outlined
The current selection. An outline, never a fill — that is what stops “you chose this” reading as “tap this”.
Amber mark
You did this. The cross-off ring, stars, the active-tab rule.
Signal red
Failure and destructive only. Never a primary action, so red always means something.
Today one hue does all five jobs. #ff5c7a has 66 uses, of which 14 are failure styles — so failure is rendered in the happy colour, and on the Remote a pink “Scan Wi-Fi” and a pink “could not reach it” occupy the same 40 points.
Label set · categorical only, never text
SMPTE test-card bars pulled to print saturation. Assigned by a hash of the title id, so a shelf of unmatched imports reads as varied spines rather than uniform sludge. All clear 3:1 as UI components; the last three do not clear 4.5:1, hence never text.
